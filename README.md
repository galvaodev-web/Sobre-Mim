# Sobre mim — Guilherme Galvão

Portfólio pessoal com as informações do currículo: apresentação, competências, projetos, experiência profissional, formação e contato.

## Como abrir

Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Organização

- `index.html`: conteúdo da página, separado por seções comentadas.
- `style.css`: cores, estilos compartilhados, seções e ajustes para celular.

Para alterar as cores, edite as variáveis no início do CSS. O layout utiliza Grid e Flexbox, com ajuste para telas de até 760px.
